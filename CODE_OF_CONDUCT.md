# Code of Conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

**In short:**
- Be respectful and inclusive.
- Give constructive feedback.
- Never harass anyone.
- Remember that the people this product serves, karigars and small jewellers, deserve the same respect in our code, copy and conversations.

Report unacceptable behaviour to the team lead (contact in [TEAM.md](docs/08-project/TEAM.md)). Reports are handled confidentially.
